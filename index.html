The Reality

Your degree taught you to write code. The industry needs something else.

Fresh graduates entering software companies today find themselves in environments where AI-assisted coding is the default. Developers use Claude Code, Codex, Cursor, and Antigravity to generate, review, and ship software at a pace that was impossible two years ago.

The gap isn't raw coding ability. Most graduates can write Python or JavaScript. The gap is workflow fluency — decomposing problems into AI-executable tasks, reviewing AI-generated code critically, and operating in a team where everyone is using AI simultaneously.

Universities teach students to write code. The industry now needs engineers who know how to orchestrate code — using themselves, AI agents, and automated pipelines in concert.

"AI fluency is not a feature to bolt onto an engineering education. It is the new baseline."

Selection

We pick for potential. Not grades.

This is not a course you register for. It's a program you apply to. We keep cohorts small — 20 students — so every person gets real mentorship, real code reviews, and a team that pushes them.

We're looking for students who are hungry to build, honest about what they don't know, and ready to be uncomfortable in the best possible way.

The Program

Three phases. One real product.
Built by you.

You don't build toy projects. You build one full-stack web application — live on the internet — that grows in complexity from your first week to your last. Read the full student guide →

P1
Foundations — Get something live.
Weeks 1–5
Master the AI-first development loop: spec → prompt → generate → review → test → commit. Set up a real dev environment. Build your first full-stack app. By Week 5, your squad ships an MVP to a real URL and demos it to external guests.
W1 · First Ship W2 · Build a Backend W3 · Connect Frontend + Backend W4 · Persist Your Data W5 · MVP Sprint
🎯 Deliverable: Working MVP deployed publicly
P2
Depth — Build at team scale.
Weeks 6–11
Add auth, integrations, and a test suite. Run real sprint ceremonies — standups, retros, PR reviews. Learn to work as an engineering team where everyone is using AI at the same time. Internal beta where squads try to break each other's apps.
W6 · Auth Sprint W7 · Data Modeling W8 · Integrations W9 · Testing Sprint W10 · Feature Sprint W11 · Internal Beta
🎯 Deliverable: Feature-complete v1 product
P3
Craft — Ship with confidence.
Weeks 12–16
Security audit, performance optimization, refactoring AI-generated technical debt. Polish the product. Write documentation someone else can actually follow. Prepare a launch — then do it. Demo Day is public, with industry professionals in the room.
W12 · Security Audit W13 · Performance Sprint W14 · Polish + Docs W15 · Launch Prep W16 · Demo Day
🎯 Deliverable: Polished v1 launch + portfolio case study
The AI Coach

Your first point of contact. Always on.

"You're not just learning about AI-assisted workflows. You're living inside one."

Every student has access to a purpose-built AI Coach — a set of configured AI tools scoped specifically to this program's curriculum, your projects, and your squad. It's not a generic chatbot.

Code Review Agent. Debugging Partner. Architecture Advisor. Prompt Coach. Sprint Assistant. Concept Tutor. Weekly Reflection Interviewer. Course Coordinator.

Human coaches are reserved for the moments AI can't handle: judgment calls, motivation, and real-world perspective. The AI Coach absorbs everything else — so you get support on demand, 24/7.

🧠 Course Coordinator
Tracks your progress, nudges you when you're falling behind, briefs coaches before check-ins.
🔍 Code Review Agent
Reviews PRs for correctness, security, and readability. Flags over-reliance on AI patterns.
🐛 Debugging Partner
Walks you through bugs Socratically — asks questions, doesn't give answers. Builds your instincts.
🏗️ Architecture Advisor
Reviews system design decisions and flags anti-patterns before they become technical debt.
✍️ Prompt Coach
Reviews the prompts you write to your coding AI tools. Meta-AI literacy as a skill.
📋 Sprint Assistant
Helps your squad break down requirements into tasks and keep the sprint on track.
📚 Concept Tutor
Answers conceptual questions about full-stack development with curriculum-aware context.
🪞 Reflection Interviewer
Weekly async check-in. Surfaces blockers and escalates to human coaches when needed.
