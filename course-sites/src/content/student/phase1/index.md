## What you'll learn

<ul class="outcomes-list">
  <li>Set up and operate an AI-assisted development environment</li>
  <li>Apply the AI-first engineering loop to real tasks: Spec → Prompt → Generate → Review → Test → Commit</li>
  <li>Build a full-stack web app: frontend, backend, database, deployment</li>
  <li>Write prompts that produce useful, targeted code</li>
  <li>Read and critically evaluate code you didn't write</li>
  <li>Use Git with basic team discipline</li>
  <li>Demo a product coherently to a non-technical audience</li>
</ul>

## The weekly rhythm

Each week follows the same structure so you always know what kind of day it is.

| Day | What happens |
|-----|-------------|
| **Monday** | Concept session (90 min) + hands-on lab |
| **Tuesday** | Squad build time + AI Coach check-in |
| **Wednesday** | Skill workshop (60 min) + build time |
| **Thursday** | Build time + peer review activity |
| **Friday** | Demo/share-out (30 min) + weekly reflection |

## Month 1 assessment

At the end of Week 4 you'll complete your first **Code Walkthrough** — a 10-minute 1:1 with a coach where you explain sections of your codebase, including AI-generated parts. No written exam. No trick questions. Just: can you explain what your code does?
