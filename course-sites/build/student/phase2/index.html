Phase 2 · Weeks 6–11

Depth

Team-scale engineering. Authentication, integrations, testing, CI/CD — and the habits of a professional engineering team.

Phase 2 content coming soon

Phase 2 week-by-week guides will be published before the start of Week 6. In the meantime, see the Phase 2 overview in the program concept note for what's ahead.

What's coming in Phase 2

Week 6 — Auth Sprint: Add user accounts to your MVP. First full PR review cycle between squads.

Week 7 — Data Modeling: Redesign your database schema with AI help. Learn when AI gets schema design wrong.

Week 8 — Integrations: Add at least two external service integrations (payments, email, maps, AI APIs).

Week 9 — Testing Sprint: Write tests for what you've built. Introduce CI — tests must pass before PRs merge.

Week 10 — Feature Sprint: Build v1's headline features with full sprint ceremonies.

Week 11 — Internal Beta: Squads swap products and try to break each other's apps. Bug triage and fixes.
