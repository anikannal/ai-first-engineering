Phase 1 · Weeks 1–5

Foundations

Get the AI-first development loop into muscle memory. Build something real. Ship it.

Phase Goal

By the end of Week 5, your squad will have a live, deployed full-stack web application — built with AI tools, understood by every team member, and demoed to a real audience.

What you'll learn

  • Set up and operate an AI-assisted development environment
  • Apply the AI-first engineering loop to real tasks: Spec → Prompt → Generate → Review → Test → Commit
  • Build a full-stack web app: frontend, backend, database, deployment
  • Write prompts that produce useful, targeted code
  • Read and critically evaluate code you didn't write
  • Use Git with basic team discipline
  • Demo a product coherently to a non-technical audience

The weekly rhythm

Each week follows the same structure so you always know what kind of day it is.

Day What happens
Monday Concept session (90 min) + hands-on lab
Tuesday Squad build time + AI Coach check-in
Wednesday Skill workshop (60 min) + build time
Thursday Build time + peer review activity
Friday Demo/share-out (30 min) + weekly reflection

The weeks

Week 1

First Ship

Environment setup. Your first AI-generated project. Something live on the internet by Friday.

 Week 2

Build a Backend

Build a REST API with AI assistance. Call an external API. Debug AI-generated code systematically.

 Week 3

Connect Frontend to Backend

Handle async operations. Build a UI that reacts to real data. Make it feel like a product.

 Week 4

Persist Your Data

Design a schema. Connect to a database. Build full CRUD. Make your app remember things.

 Week 5

MVP Sprint

Sprint planning, squad collaboration, daily standups, PRs. Ship a live MVP on Friday.

Phase 1 assessment

At the end of Week 5 you'll complete your first Code Walkthrough — a 10-minute 1:1 with a coach where you explain sections of your codebase, including AI-generated parts. No written exam. No trick questions. Just: can you explain what your code does?
