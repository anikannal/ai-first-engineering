01

First Ship

"Get something live on the internet by Friday."

This Week's Goal

By Friday you will have a personal project deployed to a public URL — and you'll be able to explain every line of code in it. The app itself is simple. The habit of shipping is not.

What you'll learn this week

  • How AI coding tools fit together and how to think about them
  • Set up a professional dev environment end-to-end
  • Use the AI-first engineering loop for the first time
  • Write a structured engineering prompt
  • Read code you didn't write and explain it to someone else
  • Deploy a web app to a public URL

Monday

Concept Session

The AI-First Engineer · 90 min

**The big idea:** You are the architect and reviewer. AI is the builder. This session establishes that mental model and introduces every tool you'll use. **What gets covered:** - What changed in software engineering — and why AI fluency is now the baseline skill - Tour of the tools: Claude Code, Cursor, GitHub Copilot, Antigravity — what each does and how they differ - The context window: the most important concept to understand about AI coding tools - The AI-first loop in six steps: **Spec → Prompt → Generate → Review → Test → Commit** After this session you should be able to answer: *What is a context window, and why does it change how I structure my prompts?*
Lab

Environment Setup Sprint · 2–3 hrs

Work through this checklist. Don't move on until every item is checked. - [ ] Terminal: can navigate, create files, run scripts - [ ] Git installed and configured, GitHub account linked - [ ] Node.js + npm installed, Python installed - [ ] VS Code + Cursor installed with recommended extensions - [ ] Claude Code CLI installed and authenticated - [ ] GitHub Copilot activated - [ ] Test repo created → commit pushed → PR opened **Stuck on setup for more than 30 minutes?** Stop and ask the AI Coach (Concept Tutor) for help. If that doesn't resolve it, flag your Engineering Coach. AI Coach · Concept Tutor Use the Concept Tutor to walk through any setup blocker step by step.

Tuesday–Wednesday

Build

First Project · Your personal landing page

**The brief:** Build and deploy a personal project landing page. It needs: - A homepage with an "about" section personalised to you - One interactive element — a form, a counter, a live API fetch, your choice - A public URL that actually works **Before you write any code**, fill in this prompt template completely: 
I want to build: [description]
The tech stack should be: [frontend / backend / deployment]
The first thing it needs to do is: [specific feature]
The user will: [describe the interaction]
I do NOT want it to: [constraints]
Success looks like: [definition of done]
Then use this to prompt Claude Code. Iterate from the output. AI Coach · Prompt Coach Submit your filled-in prompt template to the Prompt Coach before you generate. You'll get feedback on it before touching code — this is the first time you'll experience AI reviewing your AI usage. AI Coach · Course Coordinator Log your project idea with the Course Coordinator so your progress is tracked from day one.

Thursday

Workshop

Code Reading · 60 min · Pairs

Swap your codebase with a partner. You have 30 minutes to read theirs and prepare answers to these three questions: 1. **What does this file do, in plain English?** 2. **Find one thing that could break — and why** 3. **Find one thing you genuinely don't understand — look it up** Then explain to each other. This is not a code review. It's a reading exercise. The goal is to build the habit of *reading before trusting* — the most important habit for working with AI-generated code.

Friday

Demo

First Demo Day · 2–3 min each

Demo your landing page to your squad. **The rule:** you must be able to explain every line of code. If someone asks "what does this function do?" and you can't answer — that's the most valuable moment of the week. Not a failure, a learning point.
Reflection

Weekly Check-in with AI Coach

AI Coach · Reflection Interviewer The Reflection Interviewer will ask you four questions this week: - What did you ship? - What was harder than expected? - What did the AI get wrong? - What do you want to be able to do by next Friday? This takes about 10 minutes. Do it before you close your laptop on Friday.

Things people get wrong in Week 1

Accepting AI output without reading it. You don't need to understand every line immediately — but you need to read every line. The Code Reading workshop on Thursday is practice for this. Apply it to your own code too.
