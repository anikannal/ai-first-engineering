What this guide is

This is your operating manual for the bootcamp. It tells you what you're doing this week, why it matters, what the AI Coach can help with, and what done looks like. Think of it as the README for the program — keep it open, refer to it daily.

How to use this guide

Navigate by phase and week using the left sidebar. Each week page tells you: the concept session topic, what you're building, how the AI Coach fits in, and what you're being assessed on. If you're ever unsure what to do next — this is the first place to look.
